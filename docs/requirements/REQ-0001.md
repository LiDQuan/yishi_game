# REQ-0001：初始化 AI 协作工作流

## 背景

为“异世界勇者安卓自动化助手”建立统一的仓库结构、ChatGPT ↔ Codex 协作流程和任务交接规范。

## 目标

- 建立约定的源码、工具、配置、模板、策略、数据、文档、交接和诊断目录。
- 明确 ChatGPT、Codex 与 Gitee 的职责边界。
- 统一任务编号及需求、实现、Review 文件命名。
- 建立 IMPLEMENT 报告和 LATEST 复审交接规范。
- 防止敏感信息进入 Git 仓库。

## 验收标准

- 所有约定目录均存在并可被 Git 维护。
- `docs/WORKFLOW.md` 完整描述角色、流程、编号、报告、交接和安全规则。
- `.gitignore` 覆盖 Android 本地配置、签名材料、环境文件、凭据和常见生成物。
- 生成 `codex/reports/IMPLEMENT-0001.md` 和 `codex/handoff/LATEST.md`。
- 初始化提交已推送到 Gitee，且本地工作树干净。

## 限制

- 不删除或覆盖已有有效文件。
- 不提交 Token、密码、Gitee PAT、签名文件或 Android `local.properties`。
- 本任务不包含业务代码、Android 构建或 ADB 真机功能测试。
